# Gerador de Horários JCA

App público (GitHub Pages): **https://wolf9611.github.io/horario-gerador/**

- CSP no navegador (restrições duras de turma/professor/disponibilidade/carga)
- Busca: greedy + min-conflicts + simulated annealing
- PDF via impressão do navegador
- Base da grade: `horario-03ago.pdf` (EEMTI José Cláudio de Araújo)

100% gratuito. Sem backend pago.
